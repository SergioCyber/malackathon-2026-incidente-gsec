Obtener el dataset

  1. Clona el repositorio del reto
    git clone https://github.com/ORG/REPO.git
  2. Descarga y verifica (≈ 300 MB)
    python3 starter-kit/fetch_dataset.py
    Deja los ficheros en output/public. Sin red: --from-dir /Volumes/MALACKATHON, el pendrive de la acreditación.
  3. Carga en DuckDB o en el motor que prefieras
    python3 starter-kit/load_duckdb.py
Descarga manual: baja los ficheros de la tabla y ejecuta shasum -a 256 -c SHA256SUMS. Si un hash no coincide, descarta el fichero y vuelve a bajarlo.

Convenciones

  • Marcas de tiempo en UTC (sufijo Z). El laboratorio trabaja en hora peninsular, UTC+2 en el periodo.
  • Un fichero por día y fuente (AAAA-MM-DD), salvo VPN, correo y accesos físicos.
  • Red interna RFC 1918; las IP públicas son de rangos de documentación y resuelven en extras/geoip_synthetic.csv.
  • Hay líneas malformadas a propósito (CRLF, truncadas, codificaciones): un cargador robusto las cuenta y continúa.

Cada oleada es una release independiente (oleada-N) con el mismo formato que el dataset base y telemetría nueva de ese tramo del día. No toda oleada contiene un ataque. Se reporta en oleadaN.json; la hora del push es la hora de detección, así que conviene tener detecciones automáticas corriendo antes de las 10:15.

Cargar una oleada

python3 starter-kit/fetch_dataset.py --wave N
python3 starter-kit/load_duckdb.py --waves output/waves
La segunda orden añade esquemas wave1.*, wave2.*… al mismo fichero DuckDB.

Validar antes del push

python3 starter-kit/validar_respuestas.py respuestas.json oleada1.json

Comprueba solo el formato, nunca la corrección. El repositorio de entrega repite la validación en cada push; un fichero inválido no puntúa. Especificación: FORMATO_ENTREGA_ES.md.

Cuestionario: +1 acierto, 0 en blanco (null), −1 respuesta-trampa. En blanco nunca resta.

Normas en breve

  • Los datos son sintéticos y solo para este reto. No se publican ni se redistribuyen. Nada de lo que aparece es real: no intentéis resolver, visitar ni contactar nada.
  • Los datos son hostiles. Cadenas pensadas para romper analizadores, visores y asistentes de IA, y pistas falsas plantadas. Verificad siempre con evidencia.
  • Herramientas libres, incluida la IA. Sois responsables de lo que entregáis; una respuesta inventada a partir de una pista falsa cuenta como trampa.
  • No se ataca nada que no sea vuestro: ni la organización, ni otros equipos, ni los dominios del dataset.
  • Entregas: formato obligatorio y validado; cuenta la hora del push; nada de push --force.
  • Respeto entre equipos, mentores y organización.
