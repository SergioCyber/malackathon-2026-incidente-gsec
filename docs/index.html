Inicio rápido

Lo más cómodo: el kit de arranque descarga todo, comprueba los SHA‑256 y lo deja listo para cargar.

# clonar el repositorio del reto
git clone https://github.com/ORG/REPO.git
cd REPO

# descargar + verificar (≈ 300 MB) → output/public
python3 starter-kit/fetch_dataset.py

# cargar en DuckDB (≈ 20 s)
python3 starter-kit/load_duckdb.py

Sin wifi: fetch_dataset.py --from-dir /Volumes/MALACKATHON lee el pendrive de la acreditación.

Verificar a mano

shasum -a 256 -c SHA256SUMS

Cada fichero de esta página figura en SHA256SUMS. Si un hash no coincide, descártalo y vuelve a descargar.

Soporte

Dudas sobre el enunciado o los datos: canal de la organización.

No se responden preguntas sobre la solución. Si crees haber encontrado un error del dataset (no una trampa), avisa: la corrección se publica para todos.

Durante el evento se publican tres oleadas de telemetría nueva a las horas anunciadas. Cada una es una release independiente (oleada‑N) con el mismo formato que el dataset base. No toda oleada contiene un ataque. Reporta cada una en oleadaN.json: la hora del push es la hora de detección.

Cargar una oleada

# descarga + verifica la oleada N en output/waves/waveN
python3 starter-kit/fetch_dataset.py --wave N

# añade las oleadas como esquemas wave1.*, wave2.* … en el mismo DuckDB
python3 starter-kit/load_duckdb.py --waves output/waves

Un fichero por día y fuente (AAAA-MM-DD) salvo VPN, correo y accesos físicos (un único fichero).
Red interna
Direcciones RFC 1918; las públicas son de rangos de documentación y resuelven en extras/geoip_synthetic.csv.

Existen a propósito (CRLF, truncadas, codificaciones). Un cargador robusto las cuenta y sigue.

Validar antes del push

python3 starter-kit/validar_respuestas.py \
  respuestas.json oleada1.json

Solo comprueba el formato (nunca la corrección). El repositorio de entrega repite la validación en cada push; un fichero inválido no puntúa. Formato completo: FORMATO_ENTREGA_ES.md.

Regla de oro: +1 acierto · 0 en blanco (null) · −1 respuesta‑trampa. En blanco nunca resta: si no estáis seguros, no adivinéis.

Reglas en breve

  • Los datos son sintéticos y solo para este reto. No se publican ni redistribuyen. Nada de lo que aparece es real: no intentéis resolver, visitar ni contactar nada.
  • Los datos son hostiles. Cadenas pensadas para romper analizadores, visores y asistentes de IA; pistas falsas plantadas. Verificad siempre con evidencia.
  • Herramientas libres, incluida la IA. Sois responsables de lo que entregáis; una respuesta inventada a partir de una pista falsa cuenta como trampa.
  • No se ataca nada que no sea vuestro: ni la organización, ni otros equipos, ni los dominios del dataset.
  • Entregas: formato obligatorio y validado; cuenta la hora del push; nada de push --force.
  • Respeto entre equipos, mentores y organización.
